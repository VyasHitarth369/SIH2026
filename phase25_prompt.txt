9. FINAL UNIVERSITY SELECTION
==================================================

This is one of the most important Phase 25 rules.

A challenge can have multiple recommended universities.

Example:

Rank 1 → University A → ACCEPT
Rank 2 → University B → ACCEPT
Rank 3 → University C → ACCEPT

The final university must be:

THE HIGHEST-RANKED ELIGIBLE UNIVERSITY THAT ACCEPTED.

Therefore:

Rank 1 accepting → selected
Rank 2 accepting → not_selected
Rank 3 accepting → not_selected

If Rank 1 rejects but Rank 2 accepts:
→ Rank 2 becomes selected.

If Rank 1 expires and Rank 2 accepts:
→ Rank 2 can become selected.

If all universities reject/expire:
→ no university is assigned.

Do NOT select a university based on:
- who responded first
- random choice
- frontend order
- match score recalculation
- manual client input

Selection must be deterministic based on:
1. valid acceptance
2. rank
